DocMind

Perguntas e respostas sobre documentos, com fontes.

  • Pipeline RAG com busca híbrida (pgvector + texto completo) e reranking.
  • Respostas em streaming com citações que abrem o trecho exato do documento.
  • Multi-organização com dados isolados e controle de uso e custo por organização.
  • Modo agente que pesquisa em etapas e mostra cada passo.
  • Ingestão em segundo plano com fila, testes automatizados, CI/CD e Docker.
  • Next.js
  • TypeScript
  • Node.js · Fastify
  • PostgreSQL + pgvector
  • Redis · BullMQ
  • Docker
  • GitHub Actions
